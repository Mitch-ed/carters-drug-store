# Carter's Drug Store

Shopify theme for Carter's Drug Store, based on [Dawn](https://github.com/Shopify/dawn), Shopify's official reference theme (v16.0.0).

## Local development

Requires the [Shopify CLI](https://shopify.dev/docs/themes/tools/cli).

```
shopify theme dev --store=<your-store>.myshopify.com
```

## Deploy

```
shopify theme push --store=<your-store>.myshopify.com
```

See `release-notes.md` for the underlying Dawn version's changelog.
